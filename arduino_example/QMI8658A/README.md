# QMI-112HZ-6：单独提高传感器采样率

本轮从用户已实测正常的 QMI-400K-5 修改，只调整一项配置：传感器输出数据率（ODR）。CTRL2 从 0x27 改为 0x26，CTRL3 从 0x57 改为 0x56；加速度计和陀螺仪同时从约 56.05 Hz 改为约 112.1 Hz，与原共用驱动采样率一致。

保持不变：±8 g、±512 dps、400 kHz I2C、repeated START、14 字节连续读取、样本计数逐字节读取、初始化、跨帧检查、每 200 ms 打印以及 d/r 命令。主程序及共用驱动未修改。

## 测试

1. 上传 QMI8658A.ino，使用 Type-C UART，串口监视器 115200。无需外部库。
2. 确认启动 QMI-112HZ-6，提示包含 ODR 112.1Hz。
3. 平放、侧立、摇晃，并持续运行约一分钟，检查数据变化和错误提示。
4. 每 200 ms 打印一次，count 增量通常应从约 11 变成约 22～23，受打印和调度延迟影响。打印频率本身不变。
5. 正常请反馈正常；异常请附启动日志、错误前后数据以及 d 的寄存器输出。CTRL2(0x03) 应为 0x26，CTRL3(0x04) 应为 0x56。

## 测试边界

本轮只验证提高传感器 ODR，不代表主控每秒读取 112 次。当前仍每 200 ms 读取并显示最新样本，会跳过中间样本。通过后再分离采样与打印、测量读取性能并精简代码，逐步满足高频应用需求。

逐字节读取、连续读取、repeated START 和 400 kHz 已在用户板上测通。112 Hz 与原驱动一致，如果也正常，可进一步缩小问题范围；尚不能据此断言原故障的唯一原因。初始化与实际使用的库版本等差异仍需核对。
