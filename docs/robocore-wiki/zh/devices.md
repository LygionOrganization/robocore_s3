# 总线设备控制步骤

先在“总线设备”扫描，点击目标 ID。扫描不识别型号，务必选择正确组件。修改 ID 时只连接目标设备，避免相同 ID 的设备一起被修改。

## TTL Node (A)

1. PWM 选择通道 1/2，先设 0，再按需增加；0–1000 表示 0–100% 占空比。
2. RGB 通道 0 控制两组灯，1/2 控制单组。界面使用 SDK 的量化色值：R=0–7、G/B=0–3，不是普通 0–255 色值。
3. 接入 S.BUS 接收机后读取通道，返回 16 个原始值与状态字节；没有接收机信号时应结合状态判断，不要只看通道数字。
4. 修改 ID 填写当前 ID 与新 ID。固件会检查新 ID 是否已有回复；操作后重新扫描。

## TTL Stepper Driver (A)

**位置模式**：设置 mode=0 → 按需使能输出 → 填写目标位置、速度、加速度和相电流参数 → 发送目标 → 读取状态。

**连续转动**：设置 mode=1 → 使能 → 设置正/负速度；速度 0 停止，失能关闭输出。参数是寄存器值，不是直接安培或角度，详见[驱动器内存表](../ttl-stepper-driver-a/memory-map.md)。

**模式 0 和 1 在一次上电期间可自由切换，无需重启；只有更改相位才需要重启。** 本界面不修改相位。切换模式会关闭输出，需要按需重新使能。

**从动同步**：为从设备保留唯一主 ID，选择 mode=2，将 leader_id 填为主设备的主 ID，再按[EDS 教程](../ttl-stepper-driver-a/operating-modes.md)连接同步接口。不要把从设备主 ID 改成与主设备相同。

“设置当前位置”是坐标基准设置，不是运动指令。位置范围 0–65534；实际距离取决于微步和分辨率设置。

## TTL Encoder E02

读取返回原始位置和速度。角度换算：`位置 / 4096 × 360°`。把机械机构放在参考位置后，执行当前位置校准。校准基准会保存，多圈累计圈数不掉电保存。不要在快速控制循环中反复写校准。

## 总线舵机

选择 SCS、HLS 或 STS/SMS 对应组件，先读取反馈，再使用低速、小幅度目标。不要把 SCS 的位置范围直接用于 STS。同步指令参考和自动化任务脚本均在 JSON 调试页。
