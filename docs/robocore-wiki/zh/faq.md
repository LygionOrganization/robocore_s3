# 故障排查

## 网页打不开

确认仍连接 Robot 热点，浏览器输入 http://192.168.4.1。关闭会切换到其他网络的功能。使用路由器模式时查询实际 DHCP 地址。USB 线不自动提供 Wi-Fi 网络。

## 扫描不到 ID

确认外部设备供电、共地、TTL 接线和波特率。总线波特率设置只改变主控。重复 ID 请逐个连接修改；扫描不能判断重复 ID，也不识别型号。

## 步进驱动模式切换后不动

模式配置会关闭输出，请按需重新使能。模式 0 与 1 可以直接切换，无需断电；只有改相位配置才需要重启。检查当前模式是否与位置/速度命令对应，电流与限位配置是否正确。

## 板载 IMU 显示未安装

检查板载 QMI8658A 与共享 I²C 接线，排查外接模块对总线的影响。固件会报告传感器不可用并继续运行。

## USB 能发送却没回复

确认使用原生 USB CDC 端口、每条命令有换行且不超过 255 字节。关闭占用端口的软件，并持续读取反馈。若通过 T=604 关闭了 USB 输出，需要重新打开；日志不是每行都为 JSON。

## 指令超时或中间动作没执行

只有一条待执行命令，新命令覆盖旧命令是预期行为。永久任务需要先 T=0 退出。多个客户端会竞争同一队列，HTTP result 只保留最新结果。不要通过无限重发配置写入解决超时，先读状态。

## “停止循环”没有停住电机

它只请求退出任务循环，不关闭电机驱动。连续速度设为 0，或失能输出。实际机械紧急停止应由项目的供电和安全设计承担。

## 上传例程后没有控制台

单元例程替换了完整固件，按[恢复教程](firmware.md)刷回。Arduino 编译找不到头文件时，按[例程依赖表](arduino.md)安装正确库及作者版本。


## IMU 读数不更新

在“板载惯性传感器”页面点击“读取一次”，或开启实时显示后轻轻倾斜、旋转主板。静止时加速度合量约为 1 g，角速度接近零；倾斜主要改变加速度各轴分量，旋转时角速度会变化。3D 姿态用于直观观察，相对航向会随时间漂移。

也可发送 `{"T":740}` 检查原始反馈。仅在 `ok:true` 时使用测量值；`sample_count` 是 24 位循环样本计数，重复计数表示同一份样本。`sample_age_ms` 表示样本距今的时间，超过 100 ms 的缓存数据返回 `imu_no_fresh_sample`。

出现错误时，记录完整回复，检查供电，并断电检查外接 OLED 等共享 I²C 外设的接线。`imu_not_present` 表示未检测到传感器，`imu_reset_failed` 或 `imu_config_failed` 表示初始化失败。实时显示在离开页面或隐藏浏览器标签页时暂停；返回后可重新开启。
