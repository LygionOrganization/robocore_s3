# 恢复完整固件

上传单元例程后，需要恢复网页控制台、总线设备控制和 JSON 通信时，使用本页下载工具。

## 下载与准备

1. 下载[Windows 完整下载工具](../../../assets/files/robocore-s3/download-tool.zip)，解压到本地目录。工具内已包含配套固件、预设烧录地址及中英文说明。
2. 备份需要保留的任务脚本和网络设置。断开执行器及动力电源，用 USB 连接主板。
3. 运行 `Verify_Package.ps1` 可核对包内文件的 SHA-256；校验不会连接或改写设备。
4. 打开 `Start_Download_Tool.bat`，使用 ESP32-S3、Factory、UART，手动选择本板实际 COM 端口。

## 使用 Type-C UART 下载

1. 用数据线连接 **Type-C UART**，在设备管理器确认端口。关闭正在占用该端口的串口监视器或其它软件。
2. 确认三项镜像路径有效、已勾选，并核对地址：

| 镜像 | 烧录地址 |
| --- | --- |
| bootloader.bin | 0x0 |
| partitions.bin | 0x8000 |
| firmware.bin | 0x10000 |

3. 选择 COM 和波特率（首次可使用 115200；连接稳定后可使用 921600），点击 START，等待完成后按 RESET。
4. 使用无线功能前连接外部天线。若原网络设置被保留，连接原热点或路由器；全新配置默认热点 **Robot**、密码 **12345678**，打开 `http://192.168.4.1`。
5. 确认网页可访问、语言切换正常、板载惯性传感器状态可读取。随后按设备额定电压重新连接动力电源和总线设备，先扫描再控制。

Type-C UART 带自动下载电路，正常情况下无需按 BOOT。若连接失败，按住 BOOT，按下并松开 RESET，再松开 BOOT，然后重新下载。

## 镜像与设置

不要把单独的 `firmware.bin` 写到 0x0。三个文件必须来自同一次构建；上表仅适用于本下载包。自定义分区或合并镜像应使用其对应地址。

**ERASE 会删除任务和网络等保存数据**，仅在需要完全重置且已备份时使用，再写入全部镜像。普通重新烧录可能保留文件系统，因此不会必然恢复默认 Wi-Fi。

已有兼容烧录工具的用户可仅下载[固件镜像包](../../../assets/files/robocore-s3/firmware.zip)。需要修改源码时，从[完整固件仓库](https://github.com/LygionOrganization/robocore_s3)获取项目，用 PlatformIO 编译；三个文件位于 `.pio/build/esp32-s3-devkitc-1-n8r8`。
