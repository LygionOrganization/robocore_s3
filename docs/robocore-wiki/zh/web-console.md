# 网页控制台

首次打开默认英文，点击右上角 **中文** 切换中文，点击 **English** 切回。浏览器允许本地存储时会记住选择；切换保留输入，不发送指令。JSON 字段和设备原始回复保持原样。

所有页面随固件提供，不依赖互联网或 CDN。桌面侧栏采用简洁蓝色圆点导航；手机通过顶部横向导航切换页面。

## JSON 调试

在顶部输入单个 JSON 对象，点击“发送指令”。结果按 rid 匹配；HTTP202 只代表接收。`ok:false` 表示失败，`dispatched:true` 仅说明旧指令已分发，不证明机械动作成功。超时不会自动重发，先读取状态再决定下一步。

“指令参考”可按类型或关键词搜索。展开条目查看用途、参数示例；“填入指令”只复制到单条编辑器，“加入脚本”追加到任务编辑器，两者都不会立即发送。详细参数见[JSON 指令集](json-api.md)。设备控制与 Wi-Fi 设置继续使用各自页面，无需在这里重复配置。

## 创建与保存任务

1. 在“自动化任务脚本”输入任务名称、说明，每行写一个 JSON 对象。使用 `{"T":51,"delay":500}` 在步骤之间等待500ms。
2. 点击“校验并保存到主板”。程序先上传草稿，逐步等待确认并回读校验，再替换目标；同名覆盖需确认。
3. 在列表中刷新并读取已保存任务，核对内容。上传中断后，可读取 `draft_` 草稿恢复编辑。
4. 设置每步额外间隔、循环次数，点击“运行已保存任务”。未保存的编辑器修改不会运行，运行前会再次确认。
5. “导出文件”保存本地编辑器内容；“导入文件”只加载到编辑器，需要再保存才写入主板。删除任务不可撤销，先导出需要保留的内容。

任务名1–32位 ASCII 字母、数字、下划线或连字符；最多64步。步骤不含 rid，也不能嵌套调用任务。`boot` 为系统保留名；`boot_user` 会在开机时自动循环执行，使用前检查全部步骤并留出等待间隔。普通任务用自定义名称。

## 停止循环

JSON 调试中的停止循环按钮发送 T=0，退出可中断任务并清空待执行命令，不等于电机急停。连续转动的步进电机应使用速度0或失能关闭输出。任务运行时先停止循环，再编辑或调试；不要同时从多个上位机持续发送指令，因为它们共用只保留最新指令的队列。

旧 `/legacy` 地址会自动跳转到 JSON 调试页，同步控制和脚本功能统一在这里使用。
